## 📚 Featured Projects

### 🦁 [ZOO_app](https://github.com/matej04-dot/ZOO_app)

A full-stack zoo operations management platform built with **Next.js 15 + React 19** (frontend) and **ASP.NET Core + SQL Server** (backend).

**What it does:**
- Centralizes zoo workflows: animal registry, enclosure management, worker scheduling, task assignment, guided tours, incident reporting, and expense tracking
- 16 controllers with 144 REST endpoints for complete operations management
- Smart scheduling with worker availability checks and conflict detection
- Recurring task generation for automated operational duties
- Dashboard analytics with PDF report generation

**Tech Stack:** Next.js • React • TypeScript • Material UI • ASP.NET Core • EF Core • SQL Server

**Key Features:**
- Animal & enclosure management with status tracking
- Worker profiles with education, licenses, and absences
- Task creation with reassignment and recurring duties
- Tour reservations with guide assignment
- Incident tracking with remediation workflows
- Live dashboard with cost analysis and alerts
